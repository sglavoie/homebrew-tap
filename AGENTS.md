# Agent instructions

This repository is a Homebrew tap. Each file in `Casks/` is one cask, usually written by the app's own release tooling, not by hand here.

## Adding a new cask

When a new file shows up in `Casks/`, update `README.md` in the same change:

1. Add a row to the **Cask** table: the cask token in backticks, then the app name linked to its `homepage` and a short description based on the cask's `desc`. Mention runtime dependencies (`depends_on`) and OS limits (`depends_on macos:`) when there are any. Keep rows sorted by token.
2. If the cask has a `zap` stanza or another uninstall behavior worth knowing, add a bullet under the upgrade/uninstall line.
3. Add a row to the **Updated by** table that names what writes the cask (for example GoReleaser or a `just` recipe) and links the source repository.

## Version bumps

Release automation does version bumps; they need no README change. Files with the header `This file was generated by GoReleaser. DO NOT EDIT.` are overwritten on every release, so make lasting fixes in the source repository's GoReleaser config, not here.

## Checks

```sh
brew style Casks/<cask>.rb
brew audit --cask sglavoie/tap/<cask>
```
