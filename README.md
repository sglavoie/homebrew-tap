# sglavoie/homebrew-tap

Homebrew casks for apps by Sébastien Lavoie.

```sh
brew install --cask sglavoie/tap/launchgrid
```

| Cask | App |
| --- | --- |
| `launchgrid` | [LaunchGrid](https://launchgrid.sglavoie.com/): a full-screen app grid for macOS 14+ |

`brew upgrade --cask launchgrid` installs new releases. `brew uninstall --cask launchgrid` removes the app and keeps your layout and settings; add `--zap` to delete those too.

The cask is updated by `just publish` in the [LaunchGrid](https://github.com/sglavoie/LaunchGrid) repository.
